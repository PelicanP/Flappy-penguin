# Flappy-penguin
This repo contains the code and assests that I used to make my first game in python, flappy penguin. It is a knock-off version of the famous flappy bird. I mess around with pygame to improve my coding skills with python in a fun way and flappy penguin in my inaugural project. Feel free to download and play my game or use my code for education purposes. My game can also be played on the browser here: 
https://pelicanp.itch.io/flappy-penguin

I did not create any of the pixel art or the music. All the sources are linked below. Check it out and support the creator.
